# Step Filtering

This page has moved to [configuration/filtering.md](configuration/filtering.md), which is the
maintained version of this guide. Note that `--step` accepts a single step name (it is shorthand for
one `--step-filter`); repeatable filters are `--step-filter`, `--step-index`, `--step-range` and
`--skip-step`, and the preview flag is `--preview-filter`.
